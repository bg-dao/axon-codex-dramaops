# Security Policy

## Supported versions

Security fixes are applied to the latest pre-release until SceneOps reaches a stable release.

## Reporting a vulnerability

Please use GitHub private vulnerability reporting for this repository. Do not include API keys, private prompts, creator media, or project exports in a public issue.

SceneOps treats credential disclosure, project-root escape, symlink traversal, unapproved paid generation, unverified runtime installation, and sensitive-data logging as security issues.
